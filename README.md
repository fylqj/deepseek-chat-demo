# DeepSeek chat-demo — Pages 部署

本仓库是 [deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) v0.1.1 的静态构建产物，用于通过 GitHub Pages 直接访问。

- 纯静态，无需构建；`index.html` + `static/`
- 首次打开在「设置」里填入自己的 DeepSeek API Key（保存在浏览器 localStorage）
- 上游代码与资源遵循 MIT 许可，见 `LICENSE`
- 已放置 `.nojekyll`，避免 Pages 走 Jekyll 处理
